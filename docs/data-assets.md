# Data assets

[Data-Assets release](https://github.com/NanashiTheNameless/FieldWatch-Nanashi/releases/tag/Data-Assets)

This is a regular release, explicitly **not latest** and **not a pre-release**. Its tag stays fixed; data assets can be refreshed without mixing downloads into the nightly APK release.

| File | Purpose |
|---|---|
| `fieldwatch-signatures-v2.json` | Current stock catalog exported from this fork's `DefaultCatalog`. The app's **Update stock catalog from GitHub** uses this file when **Stock catalog source** is **FieldWatch-Nanashi**. Nightly builds refresh it after tests and signing checks pass. |
| `fieldwatch-signatures.json` | Historical catalog 77, preserved for older consumers. Current app builds use the v2 filename. |
| `fieldwatch-sensors.geojson.gz` | Historical optional US sensor-location export: speed cameras, red lights, gunshot detectors, and other cameras. This fork currently does not load it. |
| `fieldwatch-sensors.txt` | Description and OpenStreetMap attribution/license notice accompanying the sensor dataset. |

The app includes its stock signatures, so downloading a catalog is optional for normal scanning. The legacy catalog and sensor files are retained as archives; they are not regenerated by nightly builds.

The three historical files were preserved from repository commit `aef33decba8526b26ad279344f9ba74370a8a5d3`. Sensor data is © OpenStreetMap contributors under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/); see the accompanying text file and [OpenStreetMap copyright notice](https://www.openstreetmap.org/copyright).

The stable URL for catalog updates is:

```text
https://github.com/NanashiTheNameless/FieldWatch-Nanashi/releases/download/Data-Assets/fieldwatch-signatures-v2.json
```
